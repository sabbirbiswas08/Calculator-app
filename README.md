# Supabase Calculator Web App

A modern, simple calculator frontend that stores every calculation into your Supabase table (`calculation_history`) and displays recent history.

## Files

- `index.html` - Calculator and history UI
- `styles.css` - Modern glassmorphism styling
- `app.js` - Calculator logic + Supabase insert/select integration

## Supabase configuration

This project is already configured with your provided values in `app.js`:

- Project URL: `https://rebemzjhmzmlkvlgdjgs.supabase.co`
- Anon key: included

## Required table

```sql
CREATE TABLE calculation_history (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  expression TEXT NOT NULL,
  result TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## Required RLS policies

If history is not loading/saving, run:
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

## Important: enable table access (RLS policies)

If Row Level Security is enabled (default on Supabase), you must add policies so this frontend can read/write history with the anon key:

```sql
alter table calculation_history enable row level security;

create policy "Allow anonymous read history"
on calculation_history
for select
using (true);

create policy "Allow anonymous insert history"
on calculation_history
for insert
with check (true);
```

Use only publishable/anon keys in frontend files. Never use service role key in browser code.
