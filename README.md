# Supabase Calculator (cPanel Ready)

This is a simple modern calculator web app. It saves every calculation to your Supabase table and shows the latest history.

## Included files

- `index.html` - UI structure
- `styles.css` - modern responsive design
- `app.js` - calculator logic + Supabase API calls

## Supabase values used

- Project URL: `https://rebemzjhmzmlkvlgdjgs.supabase.co`
- Publishable key: configured in `app.js`
- Legacy anon key: kept as fallback in `app.js`

## Required table

```sql
CREATE TABLE calculation_history (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  expression TEXT NOT NULL,
  result TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## Required RLS policies

If history is not loading/saving, run:

```sql
alter table calculation_history enable row level security;

create policy "Allow anonymous read history"
on calculation_history
for select
using (true);

create policy "Allow anonymous insert history"
on calculation_history
for insert
with check (true);
```

## Deploy on cPanel

1. Upload `index.html`, `styles.css`, and `app.js` to `public_html`.
2. Open your domain URL.
3. Test: `7 + 8 =` should display result and then show in history.

## Security note

Use only publishable/anon keys in frontend files. Never use service role key in browser code.
